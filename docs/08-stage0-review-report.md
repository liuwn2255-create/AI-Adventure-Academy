- `math-broad-topic-scope` 合併數與運算、測量、圖形等多項候選主題，沒有一條可涵蓋它們的單一條文。需課程專業人員選定實際首批主題，之後逐項核對官方學習表現及學習內容代碼與 PDF 節頁；目前不得作為題目目標。
