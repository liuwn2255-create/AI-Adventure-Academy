# M3-NUM-01 位值辨識教師審查題組

**文件狀態：**`draft`／待教師審查。  
**用途：**供國小三年級數學教師逐題檢視位值辨識題目草稿。  
**階段狀態：**階段 0 尚未通過。

本文件不是課綱核准、教師簽核或正式題庫，也不代表學生已學會題目所需概念。題目候選識別碼沿用 `CAND-M3-NUM-01-03`；候選 ID 不是正式題目 ID。延伸題沒有正式題目 ID。專案目前沒有核准的單元登錄 `unitId`／`unitRevision`，故本題組不能轉成可發布的 Schema v2 題目，也不能供正式關卡引用。

### 教師填寫操作規則

- 原題與延伸題各自完成一份審查紀錄，不共用題目結論。題幹、課綱與教材對應、年級適切性、答案、解說、干擾選項、難度及先備能力，依適用情況分別記錄結果、依據／證據、審查者與日期；不適用或缺資料時須說明原因，不得留白後推定通過。
- 每題「題目審查結論」只選一項：`待審查`、`通過教師內容審查`、`退回修改`、`暫緩使用`。各審查面向分別記錄 `待審查`、`通過`、`退回修改` 或 `暫緩使用`，並填寫依據；單一面向的「通過」只表示該面向有具名教師判斷及依據。
- **「通過教師內容審查」僅表示教師完成指定的內容審查，不等於單元已核准、題目已正式發布，亦不代表任何指定班級已符合使用條件。**只有所有必要且適用的逐項審查均為通過，且審查者、日期與依據齊備，整題才可選「通過教師內容審查」。任一必要項目仍待審查、被退回或被暫緩，整題不得選此結論。
- 教材版本、冊次、單元、頁碼缺漏時，不得將相應教材對應或教材範圍審查記為已確認；需補證或記錄暫緩理由。實際班級授課紀錄或先備確認缺漏時，不得判定該班可使用。依 docs/03，實際授課紀錄是指定班級使用門檻，並非單獨等同全域發布門檻；但本題組目前缺少核准的 `unitId`／`unitRevision`，已足以阻止題目轉成可發布資料。Schema v2 的必填欄位、教材主張證據及四項審查／發布門檻仍須另行符合。
- `暫緩使用` 是本表的教師審查結論，不是新增的 Schema v2 狀態。轉錄至 Schema v2 時須依 docs/03 使用既有面向狀態並在審查意見記錄暫緩原因；不可因此把 `publicationStatus` 設為 `approved`／`published`，也不可將班級使用狀態設為 `ready_for_class`。

### 題目內容

**題幹：**在數字 3,000 中，數字 3 表示幾個「千」？

| 選項 ID | 選項文字 | 設計理由 |
| --- | --- | --- |
| `m3num0103-a` | 3 個千 | 預期正解：數字 3 位於千位。 |
| `m3num0103-b` | 3 個百 | 干擾選項：將千位與百位混淆。 |
| `m3num0103-c` | 3 個十 | 干擾選項：將千位與十位混淆。 |
| `m3num0103-d` | 3 個一 | 干擾選項：將千位與個位混淆。 |

**預期答案：**`m3num0103-a`。這是答案草稿，尚未經教師審查。  
**解說草稿：**數字 3 在千位，因此表示 3 個千。教師可依教材使用的位值表徵，確認是否需補充位值位置或數量說明；不預設學生已學乘法、冪次表示或位值換算。

## 三、題目 2：延伸候選

### 題目內容

**題幹：**位值表中，千位是 3，百位、十位和個位都是 0。這個數是什麼？

| 選項 ID | 選項文字 | 設計理由 |
| --- | --- | --- |
| `m3num0103-ext-a` | 3,000 | 預期正解：依位值表把千位 3 及其餘位的 0 寫成數字。 |
| `m3num0103-ext-b` | 300 | 干擾選項：把 3 放在百位。 |
| `m3num0103-ext-c` | 30 | 干擾選項：把 3 放在十位。 |
| `m3num0103-ext-d` | 3 | 干擾選項：把 3 放在個位。 |

**預期答案：**`m3num0103-ext-a`。這是答案草稿，尚未經教師審查。  
**解說草稿：**千位是 3，表示 3 個千；百位、十位和個位都是 0，因此這個數是 3,000。

### 題目品質初檢（非教師結論）

- **題幹：**描述了表格各位值，答案目標明確；但位值表呈現方式需依實際教材確認。
- **答案唯一性：**在目前四個選項中，只有 `m3num0103-ext-a` 符合全部位值條件。
- **干擾選項：**每個錯項都將 3 放到不同位值；是否能代表學生可能的迷思、以及 0 的設定是否造成額外難度，待教師判定。
- **負擔：**不需運算，但比原題多了從位值表轉為數字符號及理解空位 0 的要求；不應在尚未教此表徵時使用。
- **解說：**指出千位 3 和其餘位值 0；是否需補教材使用的位值表視覺表示，待教師確認。

## 四、Schema v2 轉換檢核

本題組只提供供教師檢視的題目內容，不是完整的 Schema v2 JSON。若日後轉換，至少須依 [`docs/03-question-data-spec.md`](03-question-data-spec.md) 補齊及驗證：

- 正式題目 `id`、題目 `revision`，以及與題目 revision 分開的 `unitId`／`unitRevision`。

- 班級實際授課與先備能力確認須另作班級使用紀錄，不可用課綱或教材證據替代。

目前單元登錄檔不存在，沒有可核實的核准 `unitId`／`unitRevision`；教師資料及審查欄位也尚未填寫。因此兩題只能維持候選 `draft`，不得標記 `approved`／`published`、加入正式題庫或被關卡引用。此文件不代表驗證器已實作或測試。
