# M3-NUM-01 位值辨識候選題教師審查前置證據清單

**文件狀態：**`draft`／供教師審查前準備。  
**涵蓋題目：**原題 `CAND-M3-NUM-01-03` 與無正式題目 ID 的延伸候選。  
**階段判定：**階段 0 尚未通過。

本清單只盤點審查所需證據，不代表教師已審、候選已核准、單元已核准或題目已發布。空白或「待補」不得解讀為通過。不得自行填入教材頁碼、授課紀錄、教師意見或審查結論。

## 六、目前判定

原題與延伸題都缺實際教材版本及頁次、教師逐題審查、目標班級授課紀錄與先備能力確認；延伸題另須確認位值表形式及空位 0 是否已教。專案尚無核准單元版本和正式題目資料。因此兩題均維持 `draft`／待審查，不得列為正式題庫或供正式關卡引用。階段 0 **維持未通過**。
