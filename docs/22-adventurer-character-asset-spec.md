# 小小探險家角色素材規格與缺口

## 目前狀態

- 角色身份需求：以使用者孫子的實際照片為依據，不以無關通用人物替代。
- 保留的外觀要求：黑色短髮、開朗笑容、黃色翻領、彩色橫條紋校服、深藍色短褲。實際臉型、身材比例與細節以獲提供的照片為準。
- 本次只在專案目錄內搜尋既有圖片及模型素材；沒有找到照片、正面／側面／背面參考圖或 3D 模型檔。未找到可供比對的右側視角。
- 首頁原有的通用 SVG 男孩已移除。首頁與探索場景目前使用羅盤符號佔位；它不是人物參考圖，也不是 3D 模型。
- 目前沒有依孫子照片製作或核對臉型、服裝、鞋子、背包、四面圖一致性或模型的證據。

## 待提供素材

開始製作人物參考圖或模型前，請提供：

1. 可作為依據的孫子照片，並明確確認可在本專案中使用及保存的範圍。
2. 若已有轉面參考圖，請提供正面、左側、右側、背面；目前專案內四個視角都未找到。若只有單張照片，須先確認其能支持的造型範圍，不可假稱已具備四面資料。
3. 若照片未清楚呈現，請補充鞋子、背包、校服橫條顏色與排列等可供核對的視圖。不得自行猜定照片中看不清楚的細節。

請只提供製作所需的素材，避免額外個人資訊；素材進入專案前需確認授權與保存方式。

## 後續製作與驗收順序

1. 登記素材檔名、來源、使用範圍及日期；未確認授權前不納入專案資產。
2. 依同一組參考核對正面、左側、右側與背面的人物身份特徵、頭身比例、校服、短褲、鞋子及背包；缺少視角時記錄限制，不補造為已確認外觀。
3. 先由使用者確認角色參考設計，再開始建模。
4. 3D 模型完成後另行檢查模型檔是否可載入、轉面外觀是否一致，以及不同角度的臉型與服裝是否符合參考。角色參考圖不等於可用 3D 模型。
5. 在素材與模型實際存在並完成檢查前，介面只顯示非人物羅盤佔位，不宣稱角色或模型已完成。
