## 4. 現有題目與教學流程品質

### 4.1 教學說明及練習題

| 題目 | 內容一致性與答案 | 干擾選項／提示判斷 | 風險與建議 |
| --- | --- | --- | --- |
| 練習 1：3,000 中的 3 表示幾個千？ | 預定答案「3 個千」正確；三個選項中只有一個符合題幹。文字簡短。 | 「3 個百／3 個十」是可理解的位置偏移干擾。提示「找數字 3 的位置，再想位置代表幾個千」提供步驟，不直接說答案；但已給出解題路徑，須依教師審查確認作為提示是否適當。 | 練習與檢核 1 幾乎同構，會高估獨立檢核對理解的區辨力。建議檢核改用另一種表徵或要求學生解釋，而非只替換數字。 |
| 練習 2：4 個千合起來是多少？ | 預定答案 4,000 正確且唯一。 | 400／40,000 是尺度錯誤候選。提示「每個千看成 1,000，再合起來」沒有直接報出結果，但提供了完整算式方向。 | 檢核 2 以 6 個千重測同一規則，屬數值替換而非充分不同的能力取樣。需教師確認數值上限及教學順序。 |
| 練習 3：2,000 和 500 合起來是多少？ | 2,500 的算術答案正確且唯一；需明確視為合成數量／加法候選，不應只用 `N-3-1` 自動核准。 | 2,050 可表示百位位置混淆；7,000 的典型錯誤機制不明，應請教師審查是否合理，或改成能對應明確錯誤策略的干擾項。提示「500 是幾個百」有助於拆解，但可能把注意力引到算式而非位值表徵。 | 候選檢核 3 的 `3,000+200` 與此題結構仍相似；`3,020` 的錯誤機制可描述為百位與十位位置混淆，`5,000` 的錯誤來源不清。應逐一寫明干擾設計理由並由教師確認。 |

視覺教學目前是 `lessonSteps` 的文字加上重複顯示 `1,000` 方塊；它提供表徵示意，不是學生實際操作位值積木的證據。教學階段也未設理解檢核，因此不能僅因顯示教學步驟，就把六項能力標成已教。

### 4.2 補強活動與錯誤診斷

- 程式以選項設定 `errorType`，答錯後出示錯誤說明、提示，並可進入同類型補強；活動流程可操作，且資料驗證器檢查干擾選項具有錯誤標籤。
- 這些標籤是設計假設，不是經實證的學生迷思分類。一次錯答只能表示該次選擇，不應推論穩定的錯誤概念。
- Q2 將 400 與 40,000 歸在同一「數量尺度混淆」類型可能適用，但要由教師判斷是否需區分低估／高估。
- 練習 3 與補強題都問 `2,000+500`；補強重複相同題目，未證明能針對錯誤後的概念做不同方式重教。
- 三種補強都是單選題，沒有真正的積木或位值表操作。活動名稱不能當作介面中已存在實物操作或教材教具。
- 候選檢核答錯後可以選擇補強，並開始新一輪候選檢核；這是流程行為，不代表新的檢核設計已有效或正式通過。

### 4.3 獨立候選檢核與作答分類

1. 三題候選檢核都不提供提示，同一檢核輪每題鎖定一次提交；`learningUnitFlow.js` 會將錯答與獨立答對分開記錄，使用提交 ID 防止重複計數。
2. 練習／補強中，初次直接答對、看提示後答對、未使用提示而重試後答對、答錯會分開分類。這是程式中的 session 證據分類，不是正式學習測量效度證明。
3. 候選檢核重跑以新的 `checkRun` 保存；每個新檢核輪對其題目仍是一次無提示作答。回顧可顯示該輪分類，但不能把重測記錄冒充為多份互相獨立的長期證據。
4. 候選檢核題與練習題同構程度高：第 1、2 題基本是換數值重問，第 3 題仍是兩個整數數量合成。該組題目只能提供有限的近遷移候選反應，未測量拆解、表徵互換、0 佔位及陌生情境。
5. 三題沒有經核定的通過門檻 (`passCriteria` 為 `null`)；結果狀態是 `candidate_check_result_only`。不得稱為「通過正式檢核」，也不得轉成 `check_passed` 或 `objective_achieved`。

## 5. 主要品質問題及建議處理順序

1. **先釐清能力邊界：**由數學教師確認本單元候選目標及 `0` 佔位是否應在此範圍；確認 `2,000+500` 是否屬預定教學，並補足對應課綱條文／必要先備。未釐清前，Q3 應維持「課綱對應待審」而非視為 `N-3-1` 直接覆蓋。
2. **重新設計檢核藍圖：**三題目前不足以代表整個單元或六項能力。由教師先決定要抽樣的構念，再考慮以不同表徵、由數字轉位值表／積木，或說明理由的方式降低和練習題的同構性；仍須保留候選狀態。
3. **審查錯誤選項：**請教師判斷 `7,000`、`5,000` 等干擾項是否源於可辨識的兒童策略；若原因不明，避免把它們當成診斷標籤。對每個錯項分別保存理由，避免不同錯誤共用過度粗略分類。
4. **檢查提示與補強差異：**確認提示是否提供適量支架；補強應改變表示或操作方式，不只重做同題。錯誤分類仍只作假設，須透過教師觀察或其他證據核對。
5. **補足正式審查證據：**取得使用班級的教材版次、冊次、單元頁次、授課進度與先備能力；由教師逐題審查題幹、答案、解釋、干擾選項、難度及年級適切性。審查者、日期及結論保持空白直到實際簽核。
6. **另定檢核規準：**教師／課程專業人員核定檢核方式、通過條件、所需多項證據及重測原則；正式單元核准、題目發布及指定班級使用仍分開處理。

## 6. 尚待教育專業人員決定

- `N-3-1` 在本學校三年級上／下學期的具體教材位置與授課安排；領綱的年級內容表不提供校本週次。
- `n-II-1` 如何映射到本學習單元有限的候選目標，且不得將三、四年級階段要求全數宣稱為三年級要求。
- `2,000+500` 及 `3,000+200` 是否納入這個學習單元、需要何種先備加法及額外課綱對應。
- 是否教、何時教及如何評量 0 的佔位意義；不能由題目數字中出現 0 自動推定。
- 是否需要位值積木、位值表、口語／符號轉換，以及可接受的数值與題型界線。
- 三題檢核是否足以取樣指定目標；若不足，教師核定更好的能力藍圖與評量門檻。
- 各干擾選項是否代表合理且可區分的學生錯誤，以及提示與補強是否適當。
- 實際教材、校本進度、班級已授課內容、學生先備能力，以及所有逐題審查者、日期與簽核結果。
