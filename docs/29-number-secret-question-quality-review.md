## 2. 依據與審查尺度

`docs/27` 記錄曾直接查閱教育部發布版數學領綱：`N-3-1` 三年級學習內容涉及一萬以內的數、位值積木、點數、位值表徵／位值表及「千」；`n-II-1` 是三、四年級共同的第二學習階段表現，不可作為三年級特定學期或班級進度證明。本輪沒有重新讀取官方 PDF，因此沿用 docs/27 的查核紀錄，不宣稱本輪重新核對原文。即使有 `N-3-1` 範圍依據，也不能單獨證明每個候選題型都適切。

現有原型資料顯示：練習題 `secret-thousands-01..03` 分別測 3,000 的千位意義、4 個千對應 4,000、2,000 與 500 合成；練習提示及補強題是獨立原型流程。候選檢核 `CAND-CHECK-M3-NUM-01-01..03` 分別是換數值的千位辨識、千組數量轉數字符號、及 3,000+200。docs/27 已指出前三題與檢核題型近似，第三題另涉合成／加法先備；這些是既有原型，不是本輪 A–F 新候選。

本報告使用以下判斷：

- **清晰／唯一性**：依候選題面及數學關係判斷；只代表題面分析。
- **練習**：允許教學支架或提示，作為學習過程觀察，不作無提示能力結論。
- **獨立候選檢核**：作答時不提供提示；仍須教師核定題目、範圍、實施方式與判準。
- **年級適切性**：僅在官方三年級範圍能直接支持一般概念時標為有範圍依據；題目數值、表格熟悉度、先備、詞彙和實際進度一律另待教師確認。

## 4. 練習與獨立檢核界線

- **A、B、C** 在 docs/28 中定位為帶支架練習；有積木、數字位置或拆解提示，不可把答對當作獨立能力證據。
- **D、F** 是可能的無提示獨立候選檢核；D 採位值表，F 採新語境，但兩題都主要要求依位值排列數字，能力範圍仍窄。教師需確認表格是否教過、F 的閱讀負擔及「新情境」是否成立。
- **E** 涉及尚未核定的 0 佔位。教師未完成課程範圍、教材與實際授課確認前，應排除於檢核之外；不得因錯答推定學生未達正式課程要求。
- 練習／提示反應、無提示候選檢核反應、教師審查結論及學習目標達成判定是不同證據。候選題全部答對也不等於單元通過。

## 6. 建議的下一版題目藍圖

1. **保留練習方向**：A 作為積木→數字的支架練習；B 作為口語位值練習；C 先釐清加法是否屬範圍後再決定是否保留，並優先探索位值欄／積木的組成與拆解呈現。
2. **先建構表徵檢核**：以 D 作候選起點。若教師確認位值表已教，設計至少一種不同且等值的表示方式做取樣；是否需要雙向轉換須由教師按目標決定。
3. **降低情境混淆**：F 保留遷移研究用途，刪減非必要故事字詞或改用直觀圖示，避免「千盒」被誤認為課程術語；檢核重點需仍是位值而非閱讀理解。
4. **暫緩 E**：不列入正式或候選通過檢核集合，直到 0 佔位的課綱映射、教材與授課證據、教學方式及教師審查完成。
5. **教師先定藍圖再增題**：由教師確定目標能力、題型、每項需要的獨立樣本數、提示規則、可接受數值範圍及判準。只在確定缺少有效取樣時再新增題目。
6. **保留證據分類**：每一作答記錄題目、檢核輪、是否提示、首次／重試、正誤與提交唯一識別；練習、候選檢核與正式檢核分開。相同題目重試不可作為多份獨立檢核證據。

此藍圖是審查建議，不是正式題庫規格或已通過的評量方案。
