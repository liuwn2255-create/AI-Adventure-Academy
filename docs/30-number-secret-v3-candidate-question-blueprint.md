## 2. 第三版設計原則

1. 以改變表徵或作答要求取得不同證據，不以更換數字冒充新能力。
2. 教學示範與引導練習可以提供支架；獨立檢核候選不在作答中提供提示，錯後的教學回饋與補強另行進行。
3. 錯誤選項只表示可檢視的解題假設；單次選擇不能診斷學生已有穩定迷思。
4. 涉及積木、位值表、加法符號或情境閱讀時，要確認該工具／知識已教，且不是題目額外測到的負擔。
5. 每道候選題的答案正確只代表依題面可解，不代表課綱對應、年級適切性、教材進度或通過標準已核准。

## 3. 候選題草案

### DRAFT-M3-NUM-01-01｜積木組合成數字

- **用途／作答方式：**引導練習；單選。畫面清楚顯示 2 個標示「1,000」的千積木和 4 個標示「100」的百積木，十、個積木欄以空架呈現。題幹：「這些積木表示哪一個數？」選項：A `2,400`；B `2,040`；C `6,000`。
- **正確答案與解釋：**A。兩個千積木表示 2,000，四個百積木表示 400；合看是 2,400。題目不要求學生把空欄的 0 當作獨立概念作答。
- **對應能力：**數字與數量關係；具體積木轉成數字表示。
- **先備知識：**能辨認千、百積木及其單位；能讀取圖中積木數量。是否已教及空架的呈現需教師確認。
- **干擾選項理由：**B 假設將百積木錯放到十位；C 假設把積木件數相加後都當成千。兩者是待教師檢查的錯誤策略假設，不是已驗證迷思。
- **錯答提示：**「先分開數千積木和百積木。每一種積木代表哪個單位？」
- **補強活動：**讓學生把千、百積木分別放入有標籤的欄，再口述每欄數量並選數字；補強需提供真正可操作的表徵，不能只顯示活動名稱。
- **適用性／相似度：**適合作有支架練習，不適合作獨立檢核。與 docs/28 方案 A 概念相同，第三版只將空欄和積木單位標示設計得更明確；仍非全新能力證據。
- **教師待確認：**實際教材使用的積木樣式、千與百先備、空欄表示、數值範圍及合成是否混入加法要求。

### DRAFT-M3-NUM-01-02｜數字所在位置代表多少

- **用途／作答方式：**教學示範後的引導練習；單選。題幹：「在 `7,352` 中，數字 7 表示多少？」選項：A `7`；B `700`；C `7,000`。
- **正確答案與解釋：**C。依題目數字由右向左的位值位置，7 在千位，表示 7 個千，也就是 7,000。
- **對應能力：**千位的位值意義，將數字位置連到所代表的數量。
- **先備知識：**讀取四位數、辨識個十百千欄；數字範圍及位序教學待確認。
- **干擾選項理由：**A 可能只讀數字本身而忽略位置；B 可能將千位當百位。需教師審查這些選項是否對應可辨識錯誤。
- **錯答提示：**「從個位開始往左找，指出 7 所在的欄，再想那一欄的單位。」
- **補強活動：**將同一張 7 數字卡放入不同位值欄，讓學生逐次說出欄名與數量；不要將此練習誤當成已掌握的證據。
- **適用性／相似度：**練習用途；與原型 `3,000` 中 3 的題目及 docs/28 方案 B 高度同型，僅數值不同，不列入獨立檢核藍圖。
- **教師待確認：**四位數讀寫及位序是否已教；是否保留此題或改用位值表／積木改變表徵。

### DRAFT-M3-NUM-01-03｜由位值卡組成數

- **用途／作答方式：**引導練習；單選。桌面上有標籤「千、百、十、個」的四格，卡片分別寫著「4 個千」「2 個百」「3 個十」「1 個一」。題幹：「照四張卡片的數量，選出合起來的數。」選項：A `4,231`；B `4,213`；C `4,321`。
- **正確答案與解釋：**A。四張卡依千、百、十、個欄分別表示 4,000、200、30、1，合成數字 4,231。這裡的「合成」是位值表示組合，不以筆算加法速度或直式算法作評量目標。
- **對應能力：**數的組成；位值單位與數字符號的關係。
- **先備知識：**理解千百十個標籤、讀四位數；若學生需計算加總，還需確認相應加法先備。題面應能依欄直接對應，避免另測心算。
- **干擾選項理由：**B 將十與個的數字位置交換；C 將百、十位置交換。錯項可指出排列錯誤，但仍須教師確認合理性。
- **錯答提示：**「先把四張卡各自放回同名的欄，再從千位往個位讀。」
- **補強活動：**提供四欄卡槽及可拖放的單位卡，完成後再選數字；完成提示後另換一組卡做練習，避免原題原樣重做。
- **適用性／相似度：**引導練習，不作獨立檢核。相較現有 `2,000+500`，減少以算式直接要求加法，但仍與積木組數及位值表組數有能力重疊，需依藍圖分配用途。
- **教師待確認：**位值卡與欄位教具是否符合教材；「組成」是否適用本單元；如何避免隱含未教的加法記號／運算要求。

### DRAFT-M3-NUM-01-04｜數字拆成位值卡

- **用途／作答方式：**補強練習候選；單選。題幹：「數字 `5,284` 可以用哪一組位值卡表示？」選項：A「5 個千、2 個百、8 個十、4 個一」；B「5 個百、2 個千、8 個十、4 個一」；C「5 個千、2 個十、8 個百、4 個一」。
- **正確答案與解釋：**A。數字從左到右分別在千、百、十、個位，對應五個千、兩個百、八個十、四個一。
- **對應能力：**數的分解；數字符號轉成位值單位表示。
- **先備知識：**辨認四個位值欄、理解「幾個千／百／十／一」說法；是否適用此數值及語詞由教師確認。
- **干擾選項理由：**B 交換千與百；C 交換百與十。此設計以單位—數字配對錯誤為觀察線索，不作診斷結論。
- **錯答提示：**「先從最右邊找個位，再向左依序說出每一欄的名稱。」
- **補強活動：**用位值表遮住部分欄位，學生先標欄名、再配上數量卡；其後由教師觀察能否解釋，而非只重做同一選擇題。
- **適用性／相似度：**補強用途。與 DRAFT-03 都用千百十個組成數，但方向相反（數字→位值卡），可互補而非單純換數值；兩者不能合併成單一充分掌握結論。
- **教師待確認：**分解語言與數值範圍是否在教材／班級進度；是否需將「分解」限於非加法的位值描述。

### DRAFT-M3-NUM-01-05｜位值表轉成數字

- **用途／作答方式：**獨立檢核候選；無提示單選。位值表四欄由左至右為千、百、十、個，數字分別為 3、6、1、5。題幹：「這張位值表表示哪一個數？」選項：A `3,615`；B `3,165`；C `3,651`。
- **正確答案與解釋：**A。依表格欄名順序讀取各欄數字，形成 3,615。
- **對應能力：**位值表→數字符號；多位值欄位順序辨識。
- **先備知識：**已學過此種欄名方向和由表格組成數字；表格工具熟悉度與四位數進度待確認。
- **干擾選項理由：**B 交換百、十位；C 交換十、個位。應保留錯誤反應作描述，不以一次錯誤斷定學生有固定迷思。
- **錯答提示：**檢核作答前不給提示。提交後若錯，可在教學回饋階段問「你讀取的順序和表格欄名一致嗎？」不直接報出正解。
- **補強活動：**先逐欄指認欄名，再用數字卡重建表格；補強後需使用不同表示方式的新檢核，不能將重答此題算第二份獨立證據。
- **適用性／相似度：**可作單項獨立檢核候選，是本組對表格轉數字最直接的取樣；與原型三題文字問答不同，但仍只取樣一次，不足以認定整體位值能力。
- **教師待確認：**位值表是否實際教過、表格格式／欄位順序、無提示條件及是否需要第二個不同表徵樣本。

### DRAFT-M3-NUM-01-06｜數字轉成位值表

- **用途／作答方式：**獨立檢核候選；無提示單選。題幹：「數字 `2,738` 放進位值表時，哪一列正確？」選項：A「千 2、百 7、十 3、個 8」；B「千 2、百 3、十 7、個 8」；C「千 7、百 2、十 3、個 8」。
- **正確答案與解釋：**A。2 在千位、7 在百位、3 在十位、8 在個位，依欄位填入。
- **對應能力：**數字符號→位值表；與 DRAFT-05 的轉換方向相反。
- **先備知識：**讀四位數、熟悉位值表欄名與填表規則；均待教師確認。
- **干擾選項理由：**B 交換百十；C 將千位數字誤放百位並把百位數字放千位。選項需經教師確認確能區分轉換錯誤而非文字誤讀。
- **錯答提示：**獨立作答時不提示；提交後可追問「每個數字在原數的哪一個位置？」
- **補強活動：**用數字卡逐位放入對應欄，並要求學生說出位置名稱；新一輪檢核改用積木／圖示表徵，不重用相同題面。
- **適用性／相似度：**可作獨立檢核候選，與 DRAFT-05 形成方向互補；兩題使用同一種位值表，可能共享表格熟悉度，不能僅靠答對兩題認定能在其他表徵中遷移。
- **教師待確認：**目標班級是否已學填表、題型是否和教學練習過度接近、選項次序及語句是否公平。

### DRAFT-M3-NUM-01-07｜不同情境中的位值應用

- **用途／作答方式：**獨立檢核候選；無提示單選。畫面以四個圖示盒呈現「千、百、十、個」標籤，紀錄分別是 1、5、2、4。題幹：「依照四個標籤和紀錄，總數要寫成哪個數？」選項：A `1,524`；B `1,254`；C `1,520`。
- **正確答案與解釋：**A。依標籤順序，1 個千、5 個百、2 個十、4 個一組成 1,524。此題不另要求加法計算。
- **對應能力：**在不同圖像／資料情境使用位值資訊；是本專案的遷移設計候選，不宣稱為獨立核實的三年級課綱目標。
- **先備知識：**能讀懂四個圖示標籤和各欄數量；須確認情境標籤、四位數與讀題負擔均已適切教學。
- **干擾選項理由：**B 交換百、十欄；C 忽略個位數量。兩種錯誤假設須以教師審查及實際試讀確認。
- **錯答提示：**獨立作答前不提示。錯後的補救可問「你是否用到四個標籤？每個標籤的數字放在哪個位置？」
- **補強活動：**先將圖示標籤配對到位值表，再用另一種低文字負擔的圖卡情境轉成數字；不重做同一盒子題面。
- **適用性／相似度：**相較原型純文字題與位值表題，情境／視覺輸入不同；核心仍是按位值組數，與 DRAFT-05/06 重疊。可作一個候選遷移樣本，單題不足以證明穩定遷移。
- **教師待確認：**情境是否對學生真正新穎、圖示是否降低而非增加閱讀負擔、標籤概念是否已教，以及遷移是否屬本單元的評量目標。

### DRAFT-M3-NUM-01-08｜含 0 的位值表（條件式候選）

- **用途／作答方式：**條件式練習／研究候選；未確認教學範圍前不列獨立檢核。位值表：千 4、百 0、十 6、個 2。題幹：「位值表表示哪一個數？」選項：A `4,062`；B `462`；C `4,602`。
- **正確答案與解釋：**A。在固定千、百、十、個欄位的表示規則下，各欄數字依序組成 4,062；此題預期觸及百位 0 的寫法。
- **對應能力：**0 佔位候選；同時涉及位值表→數字，但 0 佔位是主要額外要求。
- **先備知識：**固定欄位位值表、含 0 的多位數讀寫及「該位沒有數量仍保留數字位置」概念；全部待教師確認。
- **干擾選項理由：**B 可能省略中間空位；C 可能將十位數字移到百位。錯項是否適齡及代表不同策略仍待教師審查。
- **錯答提示：**僅在教師已教且定位為練習時，可問「四個欄位都有保留嗎？哪一欄沒有數量？」此提示已明顯指向空位，不能用在獨立檢核。
- **補強活動：**教師先用核准教材／教具比較欄位有無數量的表示，再由學生將同一組欄位卡轉成數字；未有授課依據時不得先以此題診斷學生。
- **適用性／相似度：**與 DRAFT-05 同為表格轉數字，但增加未確認的 0 佔位要求。**條件式候選；目前不得納入正式必考或通過判準。**
- **教師待確認：**是否屬本單元目標、官方條文與教材依據、實際頁次、班級已授課及先備能力；未逐項確認前保留暫緩。

### 能力的證據組合

- **數字與數量關係**：DRAFT-01 的積木→數字，加上不同題面下的口頭說明或反向表示；不能只靠一次選擇。
- **千位位值意義**：DRAFT-02 可作練習取樣；需另有不同表徵的無提示樣本（例如 DRAFT-06 的千欄），避免與現有 `3,000` 問題同型重複。
- **組成與分解**：DRAFT-03 與 DRAFT-04 方向互補，但需教師先決定是否列為本單元目標及是否涉及加法先備；兩者各一次作答不足以判定穩定能力。
- **表徵轉換**：DRAFT-05 與 DRAFT-06 可形成表格雙向轉換的候選組合；DRAFT-01 可補充積木至數字符號。只測同一表格格式不能推廣到積木或其他情境。
- **新情境應用**：DRAFT-07 是一個視覺情境候選；情境改變不必然表示認知要求不同，且單題不能建立穩定遷移結論。
- **0 佔位**：DRAFT-08 暫不納入目標覆蓋率或正式判準；須另有課程、教材、實際授課與教師決策證據。
