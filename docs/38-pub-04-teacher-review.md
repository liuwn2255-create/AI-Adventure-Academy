# PUB-04 教師審核管理介面 — 隔離示範

本階段建立本機示範 UI（`prototype/teacher-review-demo.html`）與可測試的審核狀態機，未連接真實教師帳號、正式 D1 或發布 API。

- 四項獨立審核：課綱、年級、答案、解析；必須全部核准才進入 `approved`。
- 退回必須填寫意見，並記錄審核者、角色、時間、版本與稽核事件。
- 採用版本檢查與序列化交易，避免並行覆寫；禁止對已核准／已發布題目直接改寫。
- 本機示範登入身分只是測試假資料，**不能**當作正式身分驗證或正式教師簽核。
- 正式整合前仍須接 Cloudflare Access 真實教師角色、D1 持久化、教師簽核流程、審查者身分驗證及真實教育專業審查。
- 不合併 main、不部署、不建立付費資源、不修改正式資料。
