# PUB-05 — 遊戲發布資料只讀整合

此階段建立獨立、未部署的遊戲資料讀取介面：`GET /api/game/publications`。

- 從 D1 `publication_records` 讀取題目及關卡固定版本。
- 任何非 published 或 ID/版本不符的紀錄都會讓整批回應 fail closed（503），避免顯示未核准資料。
- 關卡只有在 `questionRefs` 全部指向已發布的精確題目版本時才會顯示；缺失或格式不合法的關卡不會顯示。
- 不提供寫入 API，不改動既有遊戲原型入口；這是供後續遊戲整合的資料邊界，不代表前端已切換正式資料來源。
- 本輪使用模擬 D1 測試，未驗證真實 D1 migration、真實課綱資料或前端 UI 行為。
- 仍需檢查真實關卡 schema 的題目引用欄位是否為 `questionRefs`；不符合時須在後續整合前調整映射。
- 不合併 main、不部署、不建立付費資源、不修改正式資料。
