## 驗證邊界

自動核算確認：Q1 `6,284` 中 8 為十位、80；新數字 `7,536` 中 5 為百位、500。Q2 `4,056 = 4,000 + 0 + 50 + 6`，去掉中間 0 寫成 456 會改變數值；遷移數 `7,032` 的位值和為 7,032。Q3 比較數的第一個不同位分別為百位、十位，較大數為 3,402、5,180。Q4 `6×1,000 + 0×100 + 3×10 + 2 = 6,032`。

這些結果只驗證候選資料內部的數學一致性，不證明題目清晰度、先備適切、課綱對應、教學效度或學生理解。提示文字只能經資料檢查避免直接出現答案字串；是否構成過度提示仍需教師判斷。
