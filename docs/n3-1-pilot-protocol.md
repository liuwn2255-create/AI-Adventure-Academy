# N-3-1「千位數的秘密」候選試教操作與觀察紀錄

> **狀態：試教準備文件，尚未核准施測。**本文件不授權教師或學生直接使用候選題。題 1、2 只有在教師明確簽核後才可進入小規模試用；題 3 維持唯讀預覽；題 4 維持停用。`M3-NUM-01` 仍為 `candidate`，Stage 0 仍為 `not_passed`。

## 1. 目前原型能記錄什麼

V2 候選流程包含題 1、2 的單選、兩層題目提示、錯答引導與答錯後重試。每次作答事件包含題組 ID／版次、活動 ID、draft 題目 ID、提交 ID、事件順序、時間、正誤、`attemptStage`、`hintViewed`、`hintUse` 與提交時提示層級；相同 `submissionId` 會被拒絕，不重複計數。提示本身不是獨立事件，匯出不記錄提示顯示的時間或提示原文；V2 沒有補強活動，`remediationCompleted` 為 false。上述欄位描述單次候選流程，不構成學生能力或迷思診斷。

候選試作狀態和教師操作問題代碼只存在本次記憶體。結果頁有教師明確操作的 JSON 匯出；不輸入姓名或學生編號，不寫入 localStorage／sessionStorage，不上傳伺服器，也不改正式成績、星星、徽章、解鎖、精熟度或正式學習紀錄。重新載入或返回後，未匯出的記憶體資料消失；已匯出的檔案須由教師依學校資料規範保管及刪除。

提示操作本身不作為獨立事件匯出，提示狀態會記在後續作答事件；V2 沒有已連接的補強活動。因此如教師另行審查並安排觀察提示時點、提示原文或完整流程補強，須使用下方紙本／本文件紀錄表，不能假稱 V2 匯出包含這些歷程。

## 5. 匯出紀錄的操作與限制

只有在候選題組結果頁，教師明確按「教師匯出本次匿名候選測試紀錄」，才會由瀏覽器下載 JSON。匯出包括隨機觀察代碼、題組／版次、時間、逐題 draft ID、提交順序與正誤、作答階段、提示是否使用及提交時提示層級，以及教師在本次測試中記錄的操作問題代碼。提示顯示不是獨立事件，JSON 不含提示原文或顯示時間；V2 沒有補強活動，故不會有補救事件。匯出不包含姓名或學生 ID。

資料只在本機瀏覽器記憶體運作，未匯出資料可用返回／重新載入丟棄；已下載檔案由教師按學校核准的保存期限手動管理。不得將檔案放入正式學習成績或精熟度資料。若執行實際學生試用，先確認學校同意／資料治理流程已完成。

## 6. 試教後獨立關卡

1. **教師內容審查：**逐題與先備審查完成；修訂需建立版次並重新審查。
2. **小規模試用核准：**教師記錄對象範圍、方案及資料安排後，才可施測核准題目。
3. **試用完成及證據判讀：**整理匿名觀察、題目修訂和限制；結果不能自動視為有效或精熟。
4. **正式發布申請：**另依正式發布防護規則審查；試用核准不會自動通過發布。

四個關卡須分別記錄核准人、日期、依據和結論。程式測試通過不代表任何教育關卡已通過。

本節把本文件的匿名、去識別及分階段決策原則延伸供六類候選活動使用；不改變各活動的核准狀態，也不表示所有活動已有適合的試教入口。實際題目 ID、能力範圍、未涵蓋能力及提示／補強現況以[三年級數學課綱與活動對照](grade3-math-curriculum-mapping.md)第 11、12 節及程式資料為準。若某活動仍無題目提示／補強，教師不可在試教中假稱功能存在。

### 7.2 試教中操作程序

1. **教師說明：**使用已審查版本，先說明此為候選活動、作答方式及提示規則。可照讀：「請先看清楚題目，再選一個答案。若這一題是獨立作答，先自己想，不使用提示；不確定可以說不確定。這次只觀察題目和操作，不會用遊戲分數判定你學會了。」教師可示範如何點選／觸控按鈕及返回方式，但不得示範本題答案或解題步驟；若示範了數學策略，該題須記為引導活動，不可列為首次獨立作答證據。若原型沒有安全的非計分示範題，不要自行新增題目，僅口頭說明控制方式。
2. **首次獨立作答：**不提供提示，記錄題目 ID、選擇／答案、是否正確、學生可觀察的解題步驟或口頭摘要。遊戲完成或操作成功另記為技術事件，不代替數學理解證據。
3. **提示階段：**只有在該題確實有已審查提示且方案允許時才開放；逐層記錄提示層級及其後作答。題目資料未提供提示時填「未提供／不適用」，不得由教師臨時暗示後仍稱為獨立作答。
4. **答錯引導／補強：**只有程式確實連接且教師已審查的補強活動才可記為補強。無補強時記「未提供」，教師可依試教方案停止該題、以口頭追問蒐集觀察，或轉為教師教學；後續作答須標明已受教學支持，不能覆寫首次答案。
5. **重試與最終檢核：**重試使用新事件紀錄並標明階段。若要做最終獨立檢核，使用教師事先核准、未被提示或補救直接揭露答案的題目／表徵；目前題組沒有獨立檢核的活動不可臨時視為有檢核。
6. **技術與安全觀察：**記錄載入、按鈕、觸控、捲動、字體、圖像辨認、焦點、網路或中斷問題。只記可觀察事實，不以學生單次錯答標記為確定迷思。

每次觀察紀錄至少包括：場次代碼、活動／題目 ID 與版本、事件順序、題目理解摘要、首次獨立反應、提示層級與提示後反應、答錯引導／已連接補強及完成情況、補救後反應、最終獨立檢核、口頭／操作證據摘要、技術問題。某階段未發生時填「未發生」，不得推測補值。

### 7.3 六類活動的觀察焦點（不是診斷結論）
