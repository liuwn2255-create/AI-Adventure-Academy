# 千位數的秘密及九類候選活動採用前待辦清單

> 本表是工作順序與完成條件，不是採用核准。所有勾選及決策欄刻意留白，需由實際負責人完成。候選狀態不因測試或文件完整而改變。候選內容清單見[候選採用狀態總覽](n3-1-candidate-adoption-status.md)。

## 決策與證據界線

| 證據類型 | 可回答的問題 | 不能替代 |
|---|---|---|
| 工程證據 | JSON／ID／答案資料一致嗎？指定程式流程是否執行？資料是否隔離？ | 官方課綱核對、教師採用、教學有效、學生精熟 |
| 專業審查證據 | 官方條文與題目目標是否相符？題目、先備、難度、提示／回饋是否適切？ | 學生實際如何作答或遷移 |
| 學習證據 | 學生在明確版本與施測條件下如何作答、解釋、用提示及遷移？ | 自動核准、普遍成效或穩定精熟 |

三類證據分別保存並由相應人員判斷。工程測試通過不等於課綱適配；課綱適配不等於教材學期進度；教師審查通過不等於學生精熟。

## 停止條件

- 未能固定來源版本或唯一 ID，先修正追溯資料，不進行採用決定。
- 答案／圖表／單位有重大疑義時，先暫緩該題；不得以通過率或教師直覺跳過核對。
- 先備、年級或教學進度無依據時，標記待確認，不推測上／下學期。
- 沒有必要同意、學生不願參與或資料保護安排不清楚時，不進行試教。
- 工程、專業審查或學習證據缺一時，不得自動顯示已核准、已試用或已精熟。
