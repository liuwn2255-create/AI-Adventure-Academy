# 千位數的秘密｜教師審查最小決策單

> **用途：**先決定哪些候選版本值得教師試閱；下列順序只是閱讀優先建議，不表示最佳、通過、採用或已核准試教。請對照[候選版本比較表](n3-1-candidate-version-comparison.md)、[教師採用審查清單](n3-1-teacher-adoption-checklist.md)及各輪 JSON 原始資料。本單不寫入教師工作台，也不收集學生個資。

## 先讀規則

- R2、R3、R4 是不同候選稿；較新版本不會自動取代舊版。R4 Q4 是措辭提案。
- 「建議優先審閱」僅表示可先檢查哪個設計是否值得教師試閱；教師可選任何版本、要求修訂或暫緩。
- 選擇題答對、提示後答對、一次新數字答對，均不單獨證明理解或穩定掌握。
- 教材出版社、版本、冊別、頁碼、學期與班級進度沒有實際依據時，維持待提供／確認。

### 若不能確認先備或課程進度

先不要決定進入試教；在下方表格記「暫緩／待確認」，列出需要教師提供的教材版本、冊別、頁碼或班級已教內容。不得用一般年級印象補推學期順序，也不得因題目答案正確而推定先備已具備。

## 停止條件

1. 題意有歧義時，先修訂文字並重新審閱，不進入試教。
2. 先備知識或課程進度不明時，暫緩；先取得教師提供的實際依據，不進入試教。
3. 評分方式無法分辨答對與理由理解時，先修訂評分方式。
4. 尚未完成學校規範要求的審查、必要同意及資料保護程序時，不進行學生資料蒐集或試教。
5. 教師尚未審閱並明確決定時，不採用、不匯入正式流程、不套用遊戲。

## 本單狀態

這是人工決策工作單，不會自動保存到教師工作台。教材版本、課程進度、教師姓名／日期、學生試教結果及選用決定均留白待填。R2、R3、R4 及所有補救候選稿仍未採用；`M3-NUM-01` 維持 `candidate`，Stage 0 維持 `not_passed`。
