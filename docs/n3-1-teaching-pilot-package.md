# 「千位數的秘密」第五輪：教師試教評估包

> **用途與狀態：**供教師在完成教材／先備確認、學校規範及必要同意後，規劃一次小規模、形成性的候選題試教。這不是學生測驗指令、正式評量、課程核准或教學成效結論。沒有完成所需的教師、學校或家長同意前，不得招募或測試學生。
>
> `M3-NUM-01` 維持 `candidate`；Stage 0 維持 `not_passed`。候選題、補救活動及修訂稿均未由本文件接入遊戲。

## 1. 試教目的與適用範圍

## 2. 不可由一次試教推論的事項

- 不因單題答對、提示後答對、完成活動或取得遊戲回饋，就判定學生已精熟位值或達成課綱目標。
- 不以本次少量、形成性觀察推論題目具有教學效度、適用所有班級或可正式發布。
- 不把某一錯誤選項直接診斷為學生迷思。先記錄學生實際說法、操作和所用提示，再將錯誤解釋列為待驗證假設。
- 不把工程測試、獨立計算答案、教師完成審查表或一次試教互相替代。
- 官方課綱本輪未重新核對 PDF，沿用既有對照紀錄；不得據此判定學期、教材冊次或本班進度。教材出版社、版本／印次、冊別、單元、頁碼及班級授課進度均待教師提供。

## 3. 試教前準備與停止條件

### 教師先確認

1. **教材及進度：**出版社、版本／印次、年級、學期、冊別、單元、頁碼、目前班級已教內容與可核對依據。未知就填「待提供」，不要推測。
2. **題目先備：**學生是否已學位名及位序、位值表讀取、每一位的單位量、中間 0 的寫法、由高位比較，以及千／百／十／個積木名稱。逐題判斷，不要因為同屬本活動就假定全部已教。
3. **題目版本：**選定 R2 題或教師審閱後選定的 R3 替代稿；不得同時顯示答案或未選版本。R3 僅為文件候選稿，未接入遊戲。
4. **補救稿：**Q1、Q2 補救選擇第二輪或第三輪草案；兩者都尚未實作、尚未連結，教師需自行準備操作材料。不得稱為遊戲內可用補救。
5. **倫理及安全：**確認自願參與、適齡說明、學校規範及所需教師／學校／家長同意；說明學生可拒答或隨時停止，不影響課程成績或待遇。
6. **材料與可及性：**紙本題面或隔離的候選原型、位值名卡（若教師選用 Q1 補救）、千百十個積木或等值材料（若教師選用 Q2 補救）、空白記錄表、計時非必要。確認字體、視力、操作及口語表達需求不成為非目標障礙。
7. **觀察者安排：**一位教師施測、一位觀察者記錄較理想；若只有一位教師，先記錄學生原話與操作，再補寫詮釋，避免把推論混入事實。

**停止／暫緩：**必要同意未完成、班級先備未確認、學生顯示不適、題目或材料有誤、介面操作阻礙作答，或施測者無法區分題目版本時，停止該題並記為未施測／程序偏離；不要用提示補足尚未教過的內容後再宣稱獨立表現。

### 匿名資料管理

使用教師臨時產生且不含個資的代碼（例如本次試用內隨機編碼）；不要記姓名、學號、身分證字號、生日、家庭資訊、聯絡方式或可推回個人的描述。若學校規範要求保存代碼對照表，須由教師依校規分開保管且限制存取；本包不要求建立該對照表。只收集回答本次教學問題所需的最少觀察，依學校規範決定保存期限及安全刪除方式。不得把紙本觀察自動輸入正式進度或上傳服務。

## 4. 建議施測流程

1. **說明與暖身：**以學生能理解的語句說明這是測試題目是否清楚，不是考試、不計分；可以說出想法、要求重讀或停止。暖身題不得使用正式候選題答案或相同數字。
2. **先做無提示首次作答：**每題讀題後先給安靜思考時間，不暗示位名、答案或解法。記錄首次選擇／作答、學生自發理由、停頓或回看位置。無作答也記錄為無作答，不代答。
3. **先記答案，再詢問理由：**使用中性追問，如「你可以說說你怎麼想嗎？」不問「是不是因為百位？」。學生理由原話或忠實摘要另欄記錄。Q2 特別區分「選出一段解釋」與「自己解釋」；Q3 特別區分「選出理由」與「自己說明比較步驟」。
4. **提示分層：**只有首次作答及理由記錄完成後，才按既定版本提供提示一；記錄提示後答案。仍需要時再提供提示二並另記。不得把任何提示後答案歸入首次獨立作答。
5. **錯答後重思：**依題目既有錯答回饋或教師核准的紙本草案，引導學生回看相關位置／表徵；記錄是自行修正、經追問修正或仍未修正。不要把回饋直接念成標準答案後再記為理解。
6. **不同數字後續檢核：**使用本包 Q1/Q2 補救草案或教師另行審查的近遷移題；先移除提示／卡片，再呈現新數字。答案、理由、支架及程序偏離分開記錄。這仍只是有限觀察，不等於穩定遷移。
7. **結束及回饋：**感謝學生投入，避免公布個別錯誤或貼上能力標籤。教師於試教後再判斷題目要保留候選、修訂或暫緩；不能自動發布或升級。

### 建議順序與題目注意事項

建議順序為 Q1 → Q2 → Q3；Q4 僅在教師事先確認文字理解、積木單位、位序及內部 0 先備後才考慮。這是控制負荷的候選安排，不是正式年級／學期順序。

- **Q1：**表格是題目表徵；學生可直接看到數字在哪欄。觀察他是否由欄位連結數量，不要聲稱此題同時測出位名辨認。
- **Q2：**選擇題的正確選項本身有完整說明。作答後另用中性開放提問，確認學生能否用自己的話描述；把這份口語證據另列，不併入選擇題答案分數。
- **Q3：**R2 選數值後請學生說理由；R3 選數值加理由後仍請學生自行口述一次。理由選擇正確不等於能獨立產生策略。
- **Q4：**文字包含多種積木數量及空位。若教師為可及性而讀題，記錄為施測支援；這可能改變閱讀條件，不與自行閱讀的結果直接合併。

## 5. Q1、Q2 補救活動候選試教步驟

下列是紙本／實物教學草案，不是軟體已連結的補救活動。請教師先選用、調整並記錄版本；若先備不符，不施作。

### Q1：位名定位（`NS-R2-REMED-Q1`；第三輪提案 `NS-R3-REMED-REV-Q1`）

1. **目標與材料：**觀察學生是否能依位序定位指定數字所在位名。第二輪草案用 6,241 數字卡及個、十、百、千位名卡；第三輪版本在此後加入無卡的新數字 8,536。
2. **操作：**讓學生由最右側開始排位名卡，指出 6,241 中指定數字 4 的位置並說明步驟。教師先聽學生如何定位，不預配正確卡序。
3. **提示：**依草案先提醒找到最右邊，再提醒每往左一格位名升高；每一層均記錄。提示內容會提供位序策略，之後的作答不能記為無提示。
4. **錯答回饋：**請學生指出從哪側開始、移動幾格，再自行重排；不直接告知目標位名。將卡片操作錯誤與口頭解釋分開記錄。
5. **新數字檢核：**若採 R3 草案，收起位名卡，以 8,536 問數字 5 所在位名；教師預期回應為百位。記錄無卡、無提示作答和理由；單次成功只作本次觀察。
6. **返回來源題：**只有觀察紀錄完成後才可回來源題重試，標記「補救後重試」，不可覆寫首次答案。
7. **教師觀察：**是否能從右側開始、是否逐格對齊、是否自我修正、是否受卡片讀字或動作影響。先備：已教位名、位序及四位數讀取，均待教師確認。

### Q2：位名—單位—數量連結（`NS-R2-REMED-Q2`；第三輪提案 `NS-R3-REMED-REV-Q2`）

1. **目標與材料：**觀察學生能否連結目標數字的位置、該位單位及代表數量。第二輪草案用 6,175 與位名／單位／數量卡；第三輪提案增加十積木操作並加入無卡的新數字檢核。
2. **操作：**學生在 6,175 圈出 7，先說位名，再選／操作對應單位材料並說明數量；若採 R3 版本，讓學生自行取用十積木，不預先配好數量。
3. **提示：**先提示定位目標數字，再提示想一個該位單位代表多少並核對材料。記錄提示層級，不將提示後完成記為獨立作答。
4. **錯答回饋：**若位名與單位不一致，先請學生重新定位；若單位正確而數量不合，請逐個核對材料代表的量，讓學生自行修改，不直接說出答案。
5. **新數字檢核：**收起積木後，呈現 4,352，問數字 5 代表多少並請學生說明一步理由；候選預期回應是 5 個十、50。答案與理由分開記錄，無提示新數字表現不等於穩定精熟。
6. **返回來源題：**可在完成新數字記錄後由教師決定是否回原 Q2 重試；以獨立欄位記錄，不改首次及提示後結果。
7. **教師觀察：**能否先定位、是否知道每根十積木代表的單位、是否能把根數連到數量、是否只靠模仿配對。先備：位名與單位對應、十積木意義、材料操作可及性，均待教師確認。

## 6. 試教紀錄、判讀與後續決定

每位學生、每個題目與每個版本使用 [`n3-1-student-response-observation-sheet.md`](n3-1-student-response-observation-sheet.md) 獨立記錄。作答判讀使用 [`n3-1-teaching-pilot-rubric.md`](n3-1-teaching-pilot-rubric.md)。至少分開記錄：首次無提示、提示一後、提示二後、錯答引導後、補救操作後、不同數字無提示檢核。

教師試教後以實際紀錄討論：題目是否需修訂、保留候選或暫緩；是否有閱讀／操作障礙；提示是否讓學生有下一步思考；錯答回饋是否讓學生自行修正；新數字表現是否與原題一致。不要設定未經教師／學校核准的通過率門檻；以描述性觀察和題目版本為單位，不把小樣本頻率說成普遍結論。

教師可記錄的決定僅供本次候選審查。建議狀態是「保留候選待修」、「保留候選待更多觀察」、「暫緩」或「提出修訂」；後續是否進入試用評估、正式審查或發布，必須另行決議。一次試教不會自動改變課程狀態。

## 7. 課綱與目前限制

本包沿用專案現有 N-3-1 對照紀錄；本輪未重新核對官方課綱 PDF，Q3 比較題及各題逐題對應仍待課程專業人員／教師確認。`n-II-*` 屬第二學習階段表現標準，不能推定三年級上下學期進度。實際教材版本、冊別、頁碼、授課進度、相關先備、補救適切性與試教同意均待教師提供／決定。沒有實際學生試教資料，亦沒有學習成效或題目有效性證據。
