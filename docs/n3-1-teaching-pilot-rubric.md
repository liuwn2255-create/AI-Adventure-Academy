# 「千位數的秘密」試教觀察規準

> **使用界線：**供教師描述單次候選試教中的作答證據及提示依賴情形，不是正式評分量表、精熟切點或自動判定規則。請逐題、逐版本、逐作答階段記錄，不要將狀態合併為一個分數。`M3-NUM-01` 仍為 `candidate`，Stage 0 仍為 `not_passed`。

## 1. 每題分開記錄的維度

每次作答至少分成三個欄位：

1. **答案結果：**正確／錯誤／部分合理／無作答／無法判定。
2. **理由證據：**能自行說明／理由不足／理由與答案矛盾／沒有理由／教師未詢問。
3. **作答支援：**首次無提示／提示一後／提示二後／錯答引導後／補救操作後／不同數字無提示檢核。

「答案正確」不能代替理由證據；「提示後答對」不能歸類為首次獨立答對；補救活動操作完成也不能直接視為理解。

## 2. 可觀察描述

| 觀察類別 | 可記錄的行為描述 | 不應直接下的結論 |
|---|---|---|
| **無提示正確，且能解釋** | 首次未看提示即答對；學生能用自己的話或可觀察操作，說明所依據的數字位置、位值單位或比較步驟；理由與答案一致。記錄學生實際說法／操作。 | 不等於穩定精熟、已達成 N-3-1、能遷移到所有數域，或正式評量通過。 |
| **答案正確但理由不足** | 首次答案正確，但未能說理由、理由只有重述題目、說法不完整或與作答過程不一致。若 Q2/Q3 是選理由題，另記「選對理由」；不視為自行產生理由。 | 不要因選對答案推論學生理解原因；也不要只因口語表達不足推論不理解。可另用低語言負荷方式觀察。 |
| **提示後才答對** | 首次錯誤或無法作答；在提示一或提示二後答對。記錄首次錯答、提示原文／層級及提示後理由。 | 不列為無提示獨立正確；不推論提示已造成長期學習。 |
| **錯答後自行修正** | 學生在錯答引導或回看資料後自行更改，記錄是哪一個提示／問題引發修正、是否能說明。 | 不自動判定為特定迷思或補救成功；教師引導可能已提供關鍵線索。 |
| **無法作答或仍錯誤** | 記錄空白、選項、操作及學生原話；區分題意不清、未教先備、讀表／閱讀／操作問題等可觀察情形。 | 不把一次錯答診斷成固定迷思、能力不足或不適合學習。 |
| **可能的迷思假設** | 只有在學生理由或操作支持時，記錄「可能把數字本身與位值混淆」等暫定假設，並附上觀察證據及其他可能解釋。 | 不將干擾選項名稱或單次反應直接當成已證實學生迷思。 |
| **不同數字的無提示檢核** | 在未看提示或材料撤除後，對新數字記錄答案及理由，指出與來源題相同／不同之處。 | 單一新題仍只是近遷移觀察，不證明持續、廣泛或穩定遷移。 |

## 3. 各題的觀察焦點

| 題目 | 答案與理由分開觀察 | 特別需要避免的過度推論 |
|---|---|---|
| Q1 `NS-R2-DRAFT-Q01`／候選替代 `NS-R3-DRAFT-Q01` | 記錄學生是否由表格欄位連結到數量 200；另問位名時，把該口頭回答獨立記錄。 | 原題只要求選數量，不能說它同時直接測得位名辨認或無表格遷移。 |
| Q2 `NS-R2-DRAFT-Q02`／候選替代 `NS-R3-DRAFT-Q02` | 記錄選項結果；再以中性問題請學生自己說明中間 0 對其他數字位置的作用。兩種證據分開。 | 選中完整正解說明，不等於學生能自行解釋中間 0 或在新數字中運用。 |
| Q3 `NS-R2-DRAFT-Q03`／候選替代 `NS-R3-DRAFT-Q03` | 記錄選出的數；另外請學生口述從千位開始比、何時找到差異及如何判斷。R3 的選理由結果與口述理由分開。 | R2 只選較大數；R3 選答案加理由仍屬理由辨認，不能直接推論獨立運用比較策略。課綱映射尚待確認。 |
| Q4 `NS-R2-DRAFT-Q04` | 記錄學生如何從文字整理千、百、十、個數量，如何處理空位，並觀察是否自行重讀或需要讀題支援。 | 答錯可能來自文字理解、積木單位、位序或空位 0 先備，不可僅標成位值迷思。 |

## 4. Q1／Q2 補救與遷移的記錄規則

- Q1 位名卡與 Q2 單位／數量卡或十積木均是候選紙本／實物流程；尚未接入遊戲。教師先記錄材料操作，再記錄無提示的新數字檢核。
- 分別標記「提示後」、「補救操作後」及「無提示新數字」；不能只用一個最終正誤欄取代歷程。
- 若教師先示範、重新措辭、讀出題目或指出欄位，需記錄支援方式；若改變了題目條件，該次反應不與標準施測直接合併。
- 成功觀察可支持教師考慮下一步候選教學調整；單次成功不證明補救有效，也不構成精熟證據。

## 5. 教師結束後的描述性摘要

教師可按題目版本整理觀察次數及情境，例如「本次幾位參與者首次無提示答對」、「提示一後有多少人修正」、「常見原話／操作步驟」、「哪些反應受讀題支援影響」。應說明實際觀察人數、題目版本、提示流程及未完成欄位，不設未經教師／學校確認的成功率門檻，也不外推至未參與學生。

後續由教師決定候選題保留、修訂或暫緩；若要另作正式評量，需有獨立的教師審查、課綱依據、適用進度及評分規準。遊戲星星、徽章、通關、提示後正確或此表的單次觀察均不得自動轉成正式成績、掌握度或解鎖條件。
