# N-3-1「千位數的秘密」第一輪教學品質與補救路徑審查

> 本文件是依目前程式與資料所作的候選品質審查，不是教師審查、課程核准、正式評量或學生試用結果。`M3-NUM-01` 維持 `candidate`；Stage 0 維持 `not_passed`。所有錯誤類型均是題目設計假設，並非已觀察或確診的學生迷思。

## 1. 範圍、方法與證據界線

檢查了 `prototype/data/numberSecretLearningUnit.js`、`prototype/data/numberSecretQuestions.js`、`prototype/numberSecretV2CandidateFlow.js`、`prototype/learningUnitEngine.js`、`prototype/learningUnitFlow.js`、`prototype/data/teacherReviewCatalog.js`、`prototype/teacherReviewRevisions.js`、`prototype/app.js`，以及既有 N-3-1 審查、題目設計、教師清單和試教文件與相關測試。

教師工作台對本活動列出 **11 個稽核項目**：既有循序練習 3 題、2,468 積木候選引導練習 1 題、既有候選檢核 3 題、V2 可作答候選題 2 題、V2 唯讀預覽 1 項、V2 停用設計 1 項。另核對 4 個實際存在的補強活動；補強題不計入上述 11 個主項目。

「程式確認」指資料或流程程式明確存在；「教學推論」是依題目構造提出的可能性，仍須學生觀察或教師判斷。本文沒有重新下載官方課綱 PDF，也沒有教材、班級授課紀錄或學生試用資料，因此不把先前文件引用視為本輪重新核實，不據此判斷特定冊次、學期或班級適切性。

### 課綱與年級依據

- 專案既有資料將 `N-3-1` 及 `n-II-1` 對應到本單元。既有 [N-3-1 教學品質審查](n3-1-teaching-quality-review.md)記載官方 PDF 頁序 25 為三年級學習內容，頁序 11 為第二學習階段學習表現；本輪未重新取得原 PDF，故本輪狀態為**引用既有核對紀錄、未重新核對原文**。
- 即使採用既有紀錄，`n-II-1` 也不能推作三年級某一學期的進度。三年級教材出版社、版本、冊別、單元、頁碼、班級實際授課順序及先備均為**待教師提供／確認**。
- `N-3-1` 可作為既有範圍參照，但不能單獨核准每道題的措辭、圖像、難度或加法先備。

## 3. 四個補強活動的真實連結狀態

| 補強題 ID | 程式中的活動 ID／設計 | 實際路由與限制 |
|---|---|---|
| `REMED-M3-NUM-PV-POSITION-01` | `ACT-M3-NUM-PLACE-VALUE-BLOCKS-REINFORCEMENT`，辨認 3,000 中 3 的位名 | 原練習／候選檢核的 `place_value_shift` 可由 `learningUnitFlow.js` 找到並進入。內容仍與原數值高度相似。 |
| `REMED-M3-NUM-PV-QUANTITY-01` | `ACT-M3-NUM-PLACE-VALUE-THOUSAND-GROUPS-REINFORCEMENT`，四組千合成 | `thousands_quantity_mismatch` 有實際路由；內容重複原本 4 個千情境。 |
| `REMED-M3-NUM-PV-COMPOSITION-01` | `ACT-M3-NUM-PLACE-VALUE-COMPOSITION-REINFORCEMENT`，2,000 與 500 合成 | `composition_place_value_confusion` 有實際路由；加法／合成範圍待教師確認，不能稱為已驗證的補救成效。 |
| `REMED-M3-NUM-PV-BLOCK-MAPPING-01` | `ACT-M3-NUM-PLACE-VALUE-BLOCK-MAPPING-REINFORCEMENT`，將十積木對到位值欄 | `possible_place_value_block_mapping` 由 2,468 練習路由實際可達；仍是候選視覺補強，待教師檢視。 |

V2 Q1/Q2 的 `remediationPolicy` 明確為 `not_provided`，兩題沒有實際補強入口。它們僅有兩層提示、錯答後引導與重試。以上兩個新增補強描述只在候選修訂資料中作文字草案，**尚未實作、尚未連結**。

## 5. 主要風險與教師審查順序

1. **先確認目標與先備（最高優先）：**提供實際教材版本、冊別、單元、頁碼、學期／班級進度及授課紀錄；確認位名、位值單位、讀表、積木表徵與相關加法是否已教。
2. **審查 V2 Q1/Q2 題目構念：**確認「哪一位」與「代表多少」是否是分開且適合的目標；審讀原提示與兩筆候選回饋／補強草案。選錯只能作待觀察線索。
3. **決定原型第 3 題及候選檢核 03 的範圍：**這些題把加法／數量合成混入位值題；確認保留於本單元、改作跨目標練習或暫緩。
4. **審查題目重複性：**候選檢核 01/02 與練習 01/02 高度同構；若需要檢核，請教師指定不同表示方向或情境，並重新審查評分規則。
5. **維持 Q3/Q4 閘門：**Q3 在先備確認及另行題目審查前唯讀；Q4 在展開表示、加法先備、目標與評分規則確認前停用。
6. **再討論試用：**只有教師完成題目審查、教材／班級進度核對、必要修訂及試用資料治理決策後，才可另行討論是否申請小規模試用；本報告不構成試用核准。

## 7. 教師待決事項

- 教材出版社、版本／印次、冊別、單元、頁碼、學期與目前班級實際進度。
- 位名、位值數量、位值表讀取與積木表示是否已教，以及適用題序。
- 原型題 03、候選檢核 03 是否屬本單元，以及如何隔離加法／合成能力。
- 兩筆候選錯答回饋是否清楚、兩個補強草案是否值得實作；若實作，需先定義活動內容與驗收方式。
- 候選檢核是否應改變表徵／情境，避免只替換數字；正式獨立檢核目的與評分規準。
- Q3 唯讀預覽何時可重新送審；Q4 維持停用所需的先備與核准證據。
- 是否及何時申請教師核准的小規模試用，並依學校規範確認同意、匿名資料、保存期限與停止條件。

**最終狀態：**`M3-NUM-01 = candidate`；Stage 0 = `not_passed`。沒有修改正式學生資料、正式成績、掌握度、解鎖狀態或已保存教師審查紀錄；沒有部署或 Git 操作。
