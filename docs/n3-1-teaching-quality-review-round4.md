## 2. 四題逐題審查

風險等級描述題目設計需關注的程度，不代表已觀察到學生困難。

| 題目 | 程式／資料確認的題面與答案 | 實際可觀察能力與不能推論的能力 | 教學品質判斷與風險 | 建議與教師待決 |
|---|---|---|---|---|
| `NS-R2-DRAFT-Q01` | 位值表 `5,206`（千5、百2、十0、個6），問「數字 2 代表多少？」選項 2、20、200、2,000；答案 C=200。解析「2 在百位、2 個百=200」。條件獨立計算 `2×100=200`，答案與解釋一致。 | **實際測量：**使用表格中指定的欄位，將數字與該位單位量連結。**不支持：**學生能自行說出位名；能不靠表格定位；能遷移到其他表示或不同數字。 | 題意單一、選項不重複；表格必須呈現位置，是必要題目資訊，不是直接列出答案。第一層找欄，第二層指出百單位量，提示提供了相當支架但沒有寫出 200。**中風險：**原 `learningObjective` 宣稱同時測位名與數量，作答卻只選數量；讀表先備未確認。選 2/20/2,000 可能源於面值、位名或讀表失誤，不能單靠選項定位原因。 | 第三輪修訂稿將目標收斂為「由指定欄位判斷代表數量」，明列位名辨認未直接測量。教師確認是否已教讀表與百的單位量，以及題目用途是否為引導練習。 |
| `NS-R2-DRAFT-Q02` | 問 `4,056` 的中間 0 有何作用，情境比較誤寫為 `456`。答案 A 說 0 佔百位、讓 5 在十位、6 在個位。獨立重建 `4,056 ≠ 456`；答案、解析相符。 | **實際測量：**從選項中辨認一段關於中間 0 及數字位置的正確說明。**不支持：**學生能不靠選項自行解釋；理解末尾 0、連續 0 或其他數域的 0。 | 中間 0 是題目焦點，沒有位值表直接列答案；兩層提示提醒看位置並比較刪除前後。正解文字本身提供完整解釋，因此選對主要是「辨認說明」，不是「產生說明」。**中高風險：**長句與四位數比較增加閱讀負荷；B、C、D 各自混合多個錯誤陳述，選項不一定能唯一代表一種錯誤原因。C 的「相同」結論與其前句亦互相衝突，增加干擾選項診斷歧義。 | 第三輪稿把目標限定為辨認正確說明，明列不能推論自行解釋能力。建議教師考慮縮短情境句、逐句核對干擾項的內部一致性，或另設要求學生自己完成一句解釋的候選題；需先確認中間 0 的教學時點。 |
| `NS-R2-DRAFT-Q03` | 比較 `3,042` 與 `3,402`，選較大數。答案 B=`3,402`。獨立比較千位相同、百位 `0<4`，答案及解析正確。 | **實際測量：**選出一對特定四位數中的較大者。**原題不能支持：**學生確實採用「第一個不同位」策略；能比較其他數域、排序或寫比較符號。 | 提示 1、2 從高位逐步引導並指出第一個不同位；不直接寫出所選答案，但已明示策略，故提示後正確不能當成無提示策略證據。原選項只有數值，雖解析說明策略，學生不必展示理由。**中風險：**`資料不足，不能比較` 是較籠統的干擾項，錯答可能是題意或信心問題，不足以診斷某一迷思。課綱對應未核實，保持空碼。 | 第三輪稿讓選項同時包含數值與理由，正確選項要求指出千位相同後比較百位；錯誤選項分別表達先看低位、千位相同即停。仍只是辨認理由，不能等同自行建構說明。教師確認比較策略先備及正式課綱對應。 |
| `NS-R2-DRAFT-Q04` | 文字描述 6 個千、0 個百、3 根十、2 個一，選數字。答案 A=`6,032`；獨立計算 `6×1000+0×100+3×10+2=6032`。各選項數值不同；B/C/D 分別可能反映把3放百位、十個位順序互換或描述重組錯誤。 | **實際測量：**將文字中的位值數量整理成四位數，包含一個空位。**不支持：**實際操作或點數積木、末尾 0、穩定遷移。 | 沒有圖表或答案直接展示數字；資料足以唯一組成 6,032。提示要求分類千百十個並將空位寫出，支架已相當明確，適合作引導練習，不是無提示檢核。**中高風險：**同時要求理解積木單位、語句解析、位序轉寫及內部 0，錯答原因可能多重；教師需確認積木名稱及語言是否已教。 | 不另造修訂版本。教師先確認四種單位名稱、空位 0、文字閱讀負荷與使用時機；若要作獨立檢核，應另設撤除提示的不同情境並取得理由作答，不能直接把本題計分解讀成完整位值掌握。 |

### 題目角色建議（候選分類，非教師核准）

- Q1：位值表引導練習；表格是必要支架。
- Q2：概念說明辨認練習；若目標是學生自行解釋，需另設產生式作答。
- Q3：含策略提示的比較練習；原版答案選擇不足以證明策略，第三輪稿改善可觀察性但仍是理由辨認。
- Q4：文字數量描述轉數字的引導練習；先備混合，未確認前暫緩作獨立計分。

以上均不得解讀為三年級特定學期的教學順序。教師可依教材及班級進度調整或否決。

## 5. 可由程式驗證與必須由教師判斷

### 可由程式／資料核驗

- ID、選項 ID 唯一；答案 ID 恰好對應一個選項。
- Q1 的百位數量 `2×100=200`；Q2 的 `4,056` 與省略中間 0 後的 `456` 不相等；Q3 `3,402 > 3,042` 且第一不同位為百位；Q4 加權位值和為 `6,032`。
- 題幹、選項與資料中答案參照是否一致；提示欄位數、回饋 key 與錯誤線索是否對應；候選狀態及補強未連結標記。
- JSON 可解析，新候選識別碼不與工作台既有題目、第二輪題目或第一輪修訂 ID 衝突。

### 必須由教師／數學教育專業人員判斷

- 官方課綱原文及逐題對應、三年級適用性、教材版本與授課順序。
- 位值表、積木、零占位、比較策略等先備是否已教；用語及閱讀負荷是否合適。
- 干擾選項是否具有實際診斷價值、題目難度、提示是否支架過多、Q2 文字敘述是否恰當。
- 候選補救活動是否值得實作、如何安排無提示轉移／返回原題，以及實際教學成效。

自動算術核驗不等於課綱核對；工程測試不等於教師審查；教師審查也不等於學生精熟。

## 6. 建議教師審查順序與待確認清單

1. 提供教材出版社、版本／印次、年級、學期、冊別、單元、頁碼與目標班級目前進度的實際證據。
2. 先決定 Q1 的位值表閱讀與百位單位先備是否符合班級；確認題目角色是否僅為引導練習。
3. 審閱 Q2 中間 0 的教學位置、題幹閱讀負荷及混合錯誤選項；決定需要「辨認說明」還是「自行產生說明」作答。
4. 審閱 Q3 第三輪答案＋理由選項，並由課程專業人員核對合適課綱；決定是否要求學生自行說明。
5. 確認 Q4 的積木單位用語、空位 0 先備與文字題負荷；未確認前勿作獨立檢核。
6. 分別審閱 Q1/Q2 補救草案的具體操作、無提示新數字轉移、回原題時點及匿名觀察紀錄方式。
7. 如教師決定進一步試用，另行明確核准及規劃學生保護、資料紀錄與停止條件；本報告不構成試用核准。

**沒有教師決定欄位在本報告中被代填。**本輪未將候選修訂匯入教師工作台，也未更改教師草稿或審查狀態。
