# N-3-1 第二版題目教師審查清單

> **用途：**教師逐題檢視 `docs/n3-1-v2-item-design.md` 中的四題候選獨立檢核，作為日後是否修訂或進入實作討論的依據。這不是正式題庫，也不是已核准的學習檢核。
>
> **目前狀態：所有題目均「尚未審查」。**本表未預填教師意見、審查結論或日期。草案代號不是正式題目 ID。`M3-NUM-01` 維持 `candidate`；Stage 0 維持 `not_passed`。

## 教師審查操作指引

1. 先依實際使用教材填寫出版社、版次／印次、年級、學期、冊別、單元、頁碼及班級已教進度；缺資料時保留「待確認」，不要從課綱代碼推定進度。
2. 逐題檢查預定能力及必要先備，判斷作答還可能受到讀題、圖像或操作影響的程度。
3. 核對題幹、選項、正解、解析與學生用語；錯誤選項僅是待驗證線索，不可單憑一次作答診斷迷思。
4. 若選「需修訂」，請寫明要改的文字、選項、解析、提示或教學支架及理由，讓後續修訂可追溯。
5. 未完成審查的題目維持「尚未審查」，不要代填審查者、日期、教材資訊或結論。
6. 個別題目通過內容審查只表示該題完成指定內容檢視；不等於整個單元獲准試教或正式發布。試教與發布須各自依本文件第 9 節及[試教操作與觀察紀錄](n3-1-pilot-protocol.md)另行決議。

工作台的題目預覽、程式測試及匯出只提供審查工具，不構成教師審查或學生學習成效證據。

## 1. 課綱及審查狀態界線

- `N-3-1` 是官方三年級學習內容，內容涉及一萬以內數、位值積木、點數、位值表徵／位值表、千及位值單位換算；官方來源與位置見第二版設計文件及專案課綱對照文件。
- `n-II-1` 是第二學習階段（三、四年級）學習表現，不能用來證明該班在某學期已教某概念。
- 課綱範圍核對、教材與班級授課確認、題目教學效度審查、程式可執行性是不同事項，請分別判定。
- 本表的候選題目如完成教師審查，也不會自動成為正式題目或正式發布評量。

### 題 1｜`V2-DRAFT-M3-NUM-01-01` 位值名稱辨識

**草案題目：**在 `4,372` 中，數字 `7` 在哪一位？

**選項：**A 個位　B 十位　C 百位　D 千位

**草案正解：**B「十位」。從右往左依序為個位、十位、百位、千位，因此 7 在十位。

**對應能力：**O1 認出數字所在的位名；不要求計算其數值。

**干擾選項設計假設：**A／C／D 可能來自位序定位混淆。這些只是選項設計假設，學生選錯不能直接視為已確認的迷思。

**提示／補救草案：**提示「先從最右邊的個位開始標位置。」補救可用空白位值欄放置數字卡，再逐步撤除欄名順序提示。

**評分規則草案：**首次作答選對 1 分；未作答 0 分；提示後作答須另外標記，不得與首次獨立作答混算。權重及是否採此規則待教師決定。

### 題 2｜`V2-DRAFT-M3-NUM-01-02` 位名與實際數量

**草案題目：**在 `5,284` 中，數字 `8` 代表多少？

**選項：**A `8`　B `80`　C `800`　D `8,000`

**草案正解：**B `80`，即 8 個十。8 位於十位，每個十代表 10，所以 8 個十是 80。

**對應能力：**O2 從位名連結到實際數量；與「認出位名」分開記錄。

**評分規則草案：**選對 1 分；如要求口頭說明，說明另記，不以選項正確替代理解證據。

### 題 3｜`V2-DRAFT-M3-NUM-01-03` 位值表轉數字

**目前工程狀態：**僅在題 1、題 2 候選試作結果頁顯示不可作答的表格預覽；未加入可作答題組。教師審查結果仍為「尚未審查」。只有教師確認目標班級已學會讀取此種位值表、四位數書寫順序及題目用語適切後，才可討論啟用為候選作答題；此確認不等於正式核准或發布。

**草案題目：**看位值表，選出它表示的數。表格：千位 3、百位 1、十位 4、個位 2。

**選項：**A `3,124`　B `3,142`　C `3,412`　D `1,342`

**草案正解：**B `3,142`。依千、百、十、個順序把 3、1、4、2 寫成四位數。

**對應能力：**O3 位值表→數字表示轉換。與積木引導練習的表徵不同。此題沒有 0，不檢核缺位／0 佔位。

**干擾選項設計假設：**A／C 可能來自相鄰欄位交換；D 可能從錯誤欄位起寫。需記錄學生實際讀表／作答過程驗證。

**提示／補救草案：**獨立檢核作答時不提供提示。作答後可提示「先寫千位，再往右寫百、十、個」，以數字卡逐欄移動補救，不立即顯示正解。

**評分規則草案：**選對 1 分；可另記學生是否按欄說明，但說明目前不是核定必要標準。

### 題 4｜`V2-DRAFT-M3-NUM-01-04` 展開表示等值判斷（條件式候選）

**草案題目：**哪一個展開表示和 `4,326` 相同？

**選項：**A `4,000＋300＋20＋6`　B `4,000＋30＋20＋6`　C `4,000＋300＋2＋6`　D `400＋300＋20＋6`

**草案正解：**A；千、百、十、個各部分為 4,000、300、20、6。

**對應能力：**O4 展開表示／等值連結；展開式使用加法，另涉及獨立能力 O5 數量合成與加法。本題不與核心純位值題合併評量。

**干擾選項設計假設：**B／C／D 分別改變百、個或千位數量；仍需確認錯誤原因是否能由學生解釋辨識。

**提示／補救草案：**獨立檢核時不給提示；作答後把各部分放回千、百、十、個欄對照。補救後的結果另記，不能覆寫首次獨立反應。

**評分規則草案：**只有教師確認展開式與必要加法先備後，才可施測；若施測，選對 1 分，理由可另記。未確認時不施測、不列入核心分數。
